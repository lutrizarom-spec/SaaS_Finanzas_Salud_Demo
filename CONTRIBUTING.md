# Contribuciones

Este repositorio **no es un proyecto de código abierto**. La licencia es propietaria y no se aceptan contribuciones externas sin un acuerdo escrito de cesión de derechos.

## Issues

Puedes abrir un issue para reportar:

- errores de la demo;
- enlaces rotos;
- problemas de documentación;
- dudas de compatibilidad.

No publiques datos financieros reales, información personal, contraseñas ni capturas con datos sensibles. Usa ejemplos ficticios.

## Pull requests

No se aceptan pull requests de código, fórmulas, diseños o datos sin coordinación previa. Un pull request enviado no implica que será revisado, fusionado ni compensado.

## Seguridad

No reportes vulnerabilidades en issues públicos. Sigue el proceso de `SECURITY.md`.
