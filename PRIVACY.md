# Privacidad

## Resumen

El libro Excel funciona localmente. No tiene macros, telemetría, enlaces externos ni conexiones a servicios del autor.

## Datos del usuario

Los datos financieros, de salud y hábitos que ingreses en el archivo se guardan en tu equipo. El autor no recibe ni procesa esos datos.

La demo pública contiene datos ficticios. No incluye información personal real.

## Repositorio y GitHub

Este repositorio se aloja en GitHub. GitHub puede recopilar datos técnicos según su propia política de privacidad. El autor no controla ese tratamiento.

## Canal de venta y pagos

Si la compra se realiza mediante una plataforma externa, esa plataforma procesa los datos de pago y contacto según sus propias políticas. El autor no almacena números de tarjeta ni claves.

## Datos en solicitudes de soporte

No envíes datos financieros reales, documentos de identidad ni información sensible en issues, correos o mensajes de soporte. Si necesitas ayuda, comparte solo capturas o ejemplos ficticios.
