# Seguridad

## Versiones soportadas

| Versión | Soporte |
|---|---|
| Demo 1.0.x | Sí, para reportes de seguridad |
| Versiones anteriores | No |

## Reportar una vulnerabilidad

No abras un issue público con detalles explotables.

Usa **GitHub Security Advisories** en este repositorio si está disponible. Si no puedes hacerlo, contacta a [@lutrizarom-spec](https://github.com/lutrizarom-spec) en GitHub con:

- descripción del problema;
- pasos para reproducirlo;
- impacto estimado;
- versión afectada;
- sugerencia de corrección, si la tienes.

No incluyas datos financieros reales, credenciales, documentos de identidad ni información sensible. Usa datos ficticios.

## Alcance

Se revisan problemas como:

- fórmulas que expongan datos ocultos;
- enlaces o contenidos inesperados;
- protecciones que permitan modificar el archivo sin autorización;
- documentación que induzca a error sobre privacidad o licencia.

## Protección de hojas

Las hojas del archivo pueden estar protegidas sin contraseña. Esa protección es una **medida disuasiva**, no un sistema DRM. No se garantiza que impida el acceso total al contenido.

## Respuesta

La revisión es voluntaria y sin garantía de tiempos. No hay programa de recompensas. El autor puede rechazar reportes que no afecten al producto o que provengan de pruebas no autorizadas.
