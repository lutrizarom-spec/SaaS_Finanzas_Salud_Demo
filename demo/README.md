# Demo pública

Archivo: `SaaS_Finanzas_Salud_Demo.xlsx`

Esta demo muestra la estética, los dashboards y la navegación de **SaaS Finanzas & Salud** con datos ficticios.

## Incluye

- 10 hojas: las 9 del libro original más `LICENCIA`.
- 2 dashboards: `dash_finanzas` y `dash_vida`.
- 8 gráficos y 4 tablas.
- Botones de navegación entre hojas.
- Datos de ejemplo de enero a marzo de 2026.
- Hoja `calc_finanzas` oculta.
- Todas las hojas protegidas como medida disuasiva.

## Límites

- Es una demo de visualización, no el producto completo.
- No contiene datos reales.
- No está pensada para registrar datos personales de forma permanente.
- No incluye soporte, actualizaciones ni licencia de uso comercial.
- La protección de hojas no es un sistema DRM.

## Cómo abrirla

1. Descarga el archivo.
2. Ábrelo con Excel de escritorio Microsoft 365 o Microsoft 2021.
3. Si aparece la vista protegida, habilita la edición para poder navegar por los botones.
4. Usa los botones de los dashboards para moverte entre hojas.

No se recomienda Excel Online, Google Sheets ni LibreOffice: el libro usa `XLOOKUP`, `MINIFS` y formatos que pueden verse distintos.
